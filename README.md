# Recherche-Analyse-Vulnerabilites
L'objectif est de mettre en pratique les méthodes de recherche, d’identification et d’analyse de vulnérabilités à partir de bases de données publiques, de scans réseau et d’outils spécialisés. Il s’inscrit dans un contexte d’Ethical Hacking &amp; Pentesting, en utilisant des outils comme Nmap et Nessus pour évaluer la sécurité d’une machine vulnérable
